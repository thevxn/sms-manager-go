# listMessages

Messages sent on a given date, paged through with the response cursor (`GET /messages`). Replaces the former `RequestList` method.

## example output

```
message ID     : e27ff0ac-87b5-4e1d-b644-5fc6029e2a11
phone number   : 420123456789
channel used   : sms
sender name set: MyCompany
message parts  : 1
sent/delivered : 1/1
price          : 1.2 CZK
```
